# STRIA

## Short description

A differential-growth design system that turns a connected curve into a controllable porous geometry and a torqued crescent enclosure, with local spacing fields, reproducible studies and geometric checks.

## Website case study

STRIA explores how an emergent pattern can become a deliberate design tool. A connected curve expands across a prescribed surface while growth, repulsion and bending compete to shape its path.

The project combines a Grasshopper surface-growth study with an independently implemented Python workflow for local spacing control, adaptive refinement, fairing and measurement. Three configurations use the same seed and evaluation conditions. A focused spacing field was selected for its open viewing band and reduced geometric conflicts.

At the proposed screen scale, the selected study produces a 28.20 m centerline and 87.7% geometric openness in a defined viewing zone, 10.3 percentage points above the uniform-spacing comparison. The full selected run reproduced exactly in the tested environment.

The result is a digital design system, a tested screen benchmark and a sculptural crescent proposal, supported by native geometry, source code, recorded states and clearly bounded geometric tests. Physical fabrication and structural performance remain untested.

A model-derived atlas and native Rhino geometry accompany two artistic architectural collages. The crescent is a non-isometric mapping study; its metrics are recorded separately from the screen benchmark.
